## Reporting a Vulnerability

We take the security of our software seriously. If you believe you have found a security vulnerability in any project within this repository, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email directly to **`adityaj0315@gmail.com`** with:
   - A detailed summary of the vulnerability
   - Steps to reproduce or proof-of-concept code
   - Potential impact of the issue
3. You will receive an acknowledgment within 48 hours with next steps.
